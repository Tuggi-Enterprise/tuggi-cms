# Confirmação: 120 palavras para 30 segundos

## Cálculo de Palavras por Segundo

### Velocidade Normal de Fala
- Português brasileiro: ~150 palavras/minuto
- Isso equivale a: **2.5 palavras/segundo**

### Com Google TTS (speed 1.2x)
- Velocidade normal: 2.5 palavras/segundo
- Com speed 1.2: 2.5 × 1.2 = **3 palavras/segundo**
- 30 segundos × 3 palavras/segundo = **90 palavras**

### Conclusão
- **120 palavras em 30 segundos = 4 palavras/segundo**
- Isso é **um pouco mais rápido** que o ideal (3 palavras/segundo)
- Mas ainda é **aceitável** e dentro de uma margem razoável
- ✅ **CONFIRMADO: 120 palavras para 30 segundos está correto** (com margem de segurança)

### Recomendação
- **Ideal**: 90-100 palavras para 30 segundos
- **Aceitável**: 100-120 palavras para 30 segundos
- **Máximo**: 120 palavras (já configurado)
